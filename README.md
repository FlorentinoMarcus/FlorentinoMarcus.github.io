# Marcus Florentino — Game Developer

Personal game-development portfolio hosted with GitHub Pages.

The site is a static HTML, CSS, and JavaScript project with no build step. Open
`index.html` directly or serve the repository root with any static file server.

## Production files

- `index.html` — page structure and portfolio content
- `assets/css/portfolio.css` — responsive design and animation
- `assets/js/portfolio.js` — intro sequence, navigation, and page behavior
- `images/home/` — homepage imagery
- `images/para-po/`, `images/relapse/`, `images/mob-control/` — project-specific imagery
- `images/shared/` — imagery shared by every page

Design and product decisions are documented in `DESIGN.md` and `PRODUCT.md`.
